ประเภทของตัวแปลภาษา

compiler คอมไพเลอร์ ทำงานได้เร็ว เนื่องจากจะทำการแปลคำสั่งทั้งหมด แล้วจึงทำงานตามคำสั่งของโปรแกรมทีหลัง
interpreter อินเตอร์พรีเตอร์ แปลทีละบรรทัดสั่งทำงานเฉพาะจุดได้

Python ทำ GUI(Graphical User Interface) ส่วนต่อประสานผู้ใช้แบบกราฟิก, web application, game, data sci, Ai, ประัมวลผลภาพ, ระบบแผนที่, สกัดข้อมูลจากเว็บไซต์ (Web Scrapping), API (Fast API, Django REST Framework), SQL, NOSQL

การย่อหน้าโค้ดโปรแกรม คือ การจัดรูปแบบคำสั่งในภาษา Python โดยแบ่งโค้ดออกเป็นกลุ่มย่อยๆ ซึ่งแต่ละกลุ่มจะต้องจัดย่อหน้าให้เท่ากัน ไม่เช่นนั้นจะเกิดข้อผิดพลาดและไม่สามารถรันโปรแกรมได้
